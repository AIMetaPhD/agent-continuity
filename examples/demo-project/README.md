# Demo project

A tiny synthetic project for trying Agent Continuity. It contains no private data.

Steps:

1. Start Agent Continuity and register this folder.
2. Create an agent definition and apply it to `CLAUDE.md`.
3. Add a memory such as "The exporter timeout is 8000 ms".
4. Create a handoff whose next step is to append a line to `notes.txt`.
5. Continue with Claude Code or Codex and inspect the session and the file.
